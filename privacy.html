Privacy policy

Personal Calendar Sync is a personal tool used only by its owner.

Data accessed

The app uses the Google Calendar scope that only allows access to calendars the app created itself. It creates, updates and deletes events in that calendar. It cannot read other calendars.

Storage

The login token is stored only on the owner's own computers. No data is stored on any server run by the app.

Sharing

No data is sold, shared with or sent to third parties.
